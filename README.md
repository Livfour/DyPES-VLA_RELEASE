# DyPES-VLA

Project page and release materials for **DyPES-VLA: Learning Shared Dynamics Priors and Embodiment-Specific Control for Cross-Embodiment Manipulation**.

## Development

```bash
npm install
npm run dev
```

Build the production site with:

```bash
npm run build
```

The repository includes a GitHub Pages workflow that publishes `dist/` from the `main` branch.

## Assets

The project page uses figures and reported results from the DyPES-VLA paper. The downloadable manuscript is available at `public/DyPES-VLA.pdf`.
